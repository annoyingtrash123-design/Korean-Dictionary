# Grammar mini-lessons, level 3: independent content review

Reviewer: content-review (independent; not the drafter). Date: 2026-11-18.
Source: `pipeline/data/grammar_lessons/3.json` (67 lessons). Checked against the curriculum meaning and variants
columns (`pipeline/data/curriculum_grammar.tsv`) and the krdict senses in `pipeline/out/core.sqlite`
(stdict in `pipeline/out/stdict.sqlite` where krdict was silent).

Per lesson: form, outcome, what changed.

| Form | Outcome | Changes |
|---|---|---|
| 같이 | approved | The “함께” compare paired two unrelated sentences; now a true minimal pair (언니같이 살고 싶다 / 언니와 함께 살고 싶다), pattern “와 함께”. |
| 이고 | approved | Usage listed “이고 저고” as a collocation (not attested; the usual form is 이것이고 저것이고); replaced by the krdict collocations “N이고 N이고 간에” and “… 가리지 않고”. “Spoken” softened (stdict examples are written too). |
| 대로 | approved | Meaning gave 제멋대로 / 마음대로 as the “each goes its own way” sense; that is krdict sense 2, “N은 N대로” (each separately). Meaning and usage fixed and an example added (너는 너대로 … 나는 나대로). |
| 으로부터 | approved | None needed. |
| 만큼 | approved | “처럼” compare pair (너만큼 노래하고 싶다) was unnatural and not a degree/manner contrast; now 형만큼 먹었다 (as much) / 형처럼 먹었다 (the same way), with the note that degree adjectives overlap. “보다” pair invented “they”; now 민준이는 …. |
| 보고 | approved | None needed (checked: krdict 보고1 “어떤 행동이 미치는 대상”; giving verbs indeed take 한테). |
| 뿐 | approved | Example 3 English (“Besides singing, … also dances well”) made faithful to 뿐만 아니라 … 도. |
| 아1 | approved | None needed. |
| 요1 | approved | Example 5 “커피 두 잔요” (after a consonant speech uses “두 잔이요”) → “아이스 커피 하나요”. The “-습니다” compare paired the ending -아요 (가요), not the particle; now the fragment 저도요 / 저도 그렇습니다. |
| 이라고1 | approved | Example 5 and usage taught “부자라고 해서” (just because), which is krdict 이라고2 (reason), not the direct-quote 이라고1; replaced by 김민준이라고 합니다 and a note that the reason use is a different particle. |
| -었었- | approved | Pitfall “지금 … 살았었어요” was wrong for two reasons (지금 + any past); now the genuine trap 결혼했었어요 (implies the marriage is over) vs 결혼했어요. Compare English “I used to live in Seoul last year” → “I lived in Seoul last year (but I don’t any more)”. Example 4 English. |
| -거든1 | approved | Usage restricted the main clause to commands/requests/promises; krdict has an intention (맛있거든 … 사 먹어야겠어요): added. The “-으면” pair had an illogical sentence (비가 그치면 길이 막힌다); now -거든/-으면 with the same proposal, the statement case left to the pitfall. |
| -는다거나1 | approved | Meaning called it a contraction; krdict lists it as one expression (now “comes from … but works as one unit”). Usage said it is always repeated; krdict has single uses (뛴다거나 소리를 지르면 안 된다). The “-기도 하고” compare called them near-synonyms while describing a real difference; reworded. |
| -는다고1 | approved | None needed (krdict -는다고1 purpose/reason; the -느라고 contrast on subjects is right). |
